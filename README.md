# Habilita

Plataforma B2B de conformidade documental de Segurança e Saúde no Trabalho (SST):
empresas que contratam terceirizados controlam documentos por trabalhador e contrato,
recebem alertas de vencimento e consultam na portaria se o trabalhador está liberado.

- Documentação: https://osamuelleite.github.io/habilita-docs/
- O desenvolvimento acontece na branch `dev`.
